Send a character reference from your app
Send the same reference with every scene. Your app stores the character; imgrouter does not remember earlier requests. Reference requests stay on the first model in a combo, even if fallback is enabled.
{
  "model": "your-model-or-combo",
  "prompt": "Same character, walking through a rainy street",
  "reference_images": ["data:image/png;base64,..."],
  "response_format": "b64_json"
}
POST /v1/images/generations · JSON extension: reference_images. Also accepts JSON /v1/images/edits with image as a data URL. Multipart uploads are not supported. Up to 3 references, 8 MiB each. No remote image fetching.
